# 缓存下载器 · Music Downloader

给 [Folia](https://github.com/chthollyphile/folia-major) 首页加一个「下载」页：把**当前歌曲**或**整个播放队列**从 Folia 自己的本地缓存导出到音乐文件夹，并写出 `.lrc` 歌词。

不联网、不调用任何在线音源接口、不解析音频地址——只是把 Folia 播放时已经落盘的缓存另存一份。

## 功能

- 首页侧边导航新增「下载」页
- **下载当前歌曲**：读取缓存，复制到系统「音乐」文件夹，文件名 `歌名 - 歌手.m4a/mp3/flac…`，同时写同名 `.lrc`
- **导出已缓存**：把当前播放队列里所有已缓存的歌一次性导出（很快，不打断播放）
- **缓存并导出全部**：自动按队列顺序播放每一首（期间静音、快速过一遍），等 Folia 缓存完就导出；完成后恢复你原来播放的歌
- 可随时停止；导出状态逐首显示
- 只读本地缓存，不发任何网络请求

## 安装

需要 **Folia 桌面版 0.7.20 及以上**，并在「设置 → 模组」里打开「模组系统」。

1. 下载仓库 zip（或 Release 里的 zip）
2. 打开 Folia「设置 → 模组」，把 zip 拖进模组面板；也可以解压后把 `music-downloader` 文件夹放进 `%APPDATA%\Folia\mods`
3. 在模组面板启用「缓存下载器」，确认弹窗后生效
4. 播放一个歌单或专辑，首页左侧导航会出现「下载」

## 音质与速度

- **音质 = Folia 当前播放音质**。缓存里保存的就是 Folia 正在播放的码率；想要高品质，先在 Folia 里把音质调到你账号允许的最高档，再播放/下载。
- 导出「已缓存」的歌是瞬时的；未缓存的歌需要 Folia 先缓存。批量下载会静音按队列快速缓存，每首通常几秒，取决于网络。

## 工作原理

Folia 播放在线歌曲时会把音频写进本地媒体缓存：

```
<缓存目录>/audio/<sha256(audio_online:<source>:<id>)>.bin
<缓存目录>/audio/<sha256(...)>.json
```

缓存目录默认 `%APPDATA%\Folia\media-cache`（跟随 Folia 设置里的缓存目录）。模组根据当前歌曲的 `source + id` 算出缓存键，读同名 `.bin`，按 MIME / 文件头判断扩展名，复制到音乐文件夹；歌词来自 Folia 正在显示的歌词，按 LRC 格式写出。不读取在线地址，也不转码。

## 已知限制

- 歌曲必须**已经缓存过**；刚切歌时缓存可能还没写完
- 批量下载会短暂切换当前播放歌曲（结束会恢复），期间会静音
- 部分音源可能不写缓存，此时这些歌无法导出
- 缓存可能被 Folia 的容量上限自动清理
- 本地歌曲本来就在硬盘上，不需要这个页面

## 权限

| 权限 | 用途 |
| --- | --- |
| `playback.control` | 批量下载时按队列顺序播放/切歌（静音），结束后恢复原来的歌曲；单首导出不需要 |

模组不联网、不收集数据；写文件只发生在系统「音乐」文件夹（用户点击导出时），按规范在提交 issue 中申报。
