# 音乐下载 · Music Downloader

给 [Folia](https://github.com/chthollyphile/folia-major) 首页加一个「下载」页：直接复用 Folia 已经适配好的在线音源，解析当前歌曲 / 整个播放队列的音频地址并保存到音乐文件夹，同时写出 `.lrc` 歌词。

不需要等缓存、不需要针对每个平台写接口——Folia 的 Omni 音源本身就会为每个平台解析音频地址，模组通过官方的 `omni.audioSourceResolved` 钩子拿到那个地址，然后交给主进程下载。

## 功能

- 首页左侧导航新增「下载」页
- **下载当前歌曲**：解析当前音源地址，保存到系统「音乐」文件夹，文件名 `歌名 - 歌手.m4a/mp3/flac…`，同时写同名 `.lrc`
- **下载整个队列**：静音快速解析队列里每首歌的地址，解析到就开始下载，可随时停止；结束后恢复原来的歌曲和进度
- 支持 Folia 支持的所有在线音源（网易云 / QQ 音乐 / 酷狗 / 汽水音乐 / 波点音乐 / YouTube Music / Spotify…），因为这些地址本来由 Folia 的音源适配器解析
- 不内置任何平台 API：不登录、不带 cookie 逻辑，全部复用 Folia 当前会话

## 安装

需要 **Folia 桌面版 0.7.20 及以上**，并在「设置 → 模组」里打开「模组系统」。

1. 下载仓库 zip（或 Release 里的 zip）
2. 打开 Folia「设置 → 模组」，把 zip 拖进模组面板；也可以解压后把 `music-downloader` 文件夹放进 `%APPDATA%\Folia\mods`
3. 在模组面板启用「音乐下载」，确认弹窗后生效
4. 播放一个歌单或专辑，首页左侧导航会出现「下载」

## 音质

下载到的是 **Folia 当前播放音质**解析出来的地址。想要高品质，先在 Folia 里把音质调到你的账号允许的最高档（例如汽水/网易云的无损档），再播放/下载。模组不改变音质。

## 工作原理

1. 模组注册 `omni.audioSourceResolved` 钩子（Folium 1.7 的实验接口）；
2. 需要下载某首歌时，模组让 Folia 播放它（批量时静音快速切歌），Folia 的音源适配器解析出音频地址，钩子把地址交给模组；
3. 模组把地址交给主进程，主进程用 Electron 的 `net` 流式下载到系统音乐文件夹，按 Content-Type 决定扩展名；
4. 当前歌曲会额外用 Folia 正在显示的歌词写出 `.lrc`。

没有按平台分别适配：新增音源只要 Folia 自己支持，这个页面就自动支持。

## 已知限制

- 下载地址带签名、绑定账号权益，部分平台可能限制并发或对非浏览器请求返回 403；失败会逐首显示
- 批量下载会静音快速切歌来解析地址（结束会恢复原歌），期间请勿关闭 Folia
- 音质取决于 Folia 设置；本地歌曲不需要这个页面
- 下载的文件仅供个人离线使用

## 权限

| 权限 | 用途 |
| --- | --- |
| `playback.control` | 解析音频地址需要让 Folia 播放对应歌曲（批量时静音快速切歌），结束后恢复原来的歌曲与进度 |

实验接口：`omni.hooks`（`audioSourceResolved`），用来拿到 Folia 已解析好的音频地址，避免重写各平台 API。

模组不收集、不上传任何数据；下载文件只写系统「音乐」文件夹（按规范在提交 issue 中申报）。
