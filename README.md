# 缓存下载器 · Music Downloader

给 [Folia](https://github.com/chthollyphile/folia-major) 的播放页加一个下载按钮：把**当前歌曲从 Folia 自己的本地缓存**复制到音乐文件夹，并同时写出 `.lrc` 歌词。

不联网、不调用任何在线音源接口、不解析任何音频地址——它只是把 Folia 播放时已经落盘的缓存文件另存一份。

## 功能

- 播放页进度条旁新增一个下载按钮（下载图标）
- 点击后把当前歌曲的缓存音频复制到系统「音乐」文件夹，文件名 `歌名 - 歌手.m4a/mp3/flac…`
- 同时写出同名 `.lrc`（含翻译行），并自动避免重名覆盖
- 命令面板里也有「下载当前歌曲到音乐文件夹」
- 只读本地缓存，不发任何网络请求

## 安装

需要 **Folia 桌面版 0.7.20 及以上**，并在「设置 → 模组」里打开「模组系统」。

1. 下载仓库 zip（或 Release 里的 zip）
2. 打开 Folia「设置 → 模组」，把 zip 拖进模组面板；也可以解压后把 `music-downloader` 文件夹放进 `%APPDATA%\Folia\mods`
3. 在模组面板启用「缓存下载器」，确认弹窗后生效
4. 播放一首歌，等它缓冲一会儿，在播放页进度条旁点下载按钮

## 工作原理

Folia 播放在线歌曲时，会把音频写进本地媒体缓存：

```
<缓存目录>/audio/<sha256(audio_online:<source>:<id>)>.bin
<缓存目录>/audio/<sha256(...)>.json
```

缓存目录默认是 `%APPDATA%\Folia\media-cache`（跟随 Folia 设置里的缓存目录）。模组根据当前歌曲的 `source + id` 算出缓存键，读同名 `.bin`，按 MIME / 文件头判断扩展名，复制到音乐文件夹；歌词来自 Folia 正在显示的歌词，按 LRC 格式写出。

模组不读取任何在线地址，也不做转码，缓存的音频是什么格式就保存什么格式。

## 已知限制

- 歌曲必须**已经缓存过**：刚切歌或缓存被清理时会提示「还没缓存完，让它再播一会儿」
- Folia 的缓存可能按流式分片保存；个别音源缓存不完整时，导出的文件可能不完整
- 本地歌曲本来就在硬盘上，不需要这个按钮
- 缓存可能被 Folia 的容量上限自动清理，想要哪首就及时点

## 隐私与合规

模组不联网、不收集数据、不上报任何内容，只在你点击按钮时读本机缓存、写系统音乐文件夹。导出的文件仅供个人离线使用，请遵守你所用音乐平台的服务条款，不要传播或商用。
